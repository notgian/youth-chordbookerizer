# The YOUTH Chordbookerizer (BETA)
This is a simple web-based utility to help expedite the process of creating/modifying chords for chordbooks of the SJRM Youth.

Input the chords and other info of the song, and simply copy paste the text into a google docs and voila! All text will be the expected format of what you need for a chordbook.

## Important Notes
1. This DOES NOT work on phones due to limitations of how the copy paste works.
2. This application is still in its BETA phase. Expect that not everything will work perfectly or will have some issues.

## For Devs (Running Locally)

Install the dependencies:

```bash
bun install
```

Start the dev server, and the app will be available at [http://localhost:3000](http://localhost:3000).

```bash
bun run dev
```
